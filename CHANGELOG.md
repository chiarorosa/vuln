# Changelog

## [Unreleased]

On `main`, not yet in a binary release:

- WebSocket proxy with frame decoding, editing and dropping
- HTTP/2 negotiation over ALPN
- Session macros that extract a fresh token and retry
- Intruder concurrency pool with a configurable limit
- Custom scan-check DSL and a CSRF form generator
- Isolated JavaScript scripting sandbox with no access to Java and with execution limits
- Local callback service (HTTP and DNS) with token expiry
- Dedicated browser bridge for extracting DOM links
- HAR import/export, codec pipeline, organizer and logger
- The build scripts honor `JAVA_HOME`

## [3.2.1]

- Repeater-first layout: URL bar, raw request editor, response with JSON syntax highlighting
- Graphite FlatLaf theme
- Offline pt-BR Wiki (`F1`) with twenty articles and search
- Proxy, Repeater, Intruder, Scanner, WebSockets, Target, Decoder, Sequencer, Comparer, TLS and Extensions
